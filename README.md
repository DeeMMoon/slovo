# Слово

Английский понемногу: карточки слов и фраз, скрытые подсказки, переводы и примеры.

**Приложение:** https://deemmoon.github.io/slovo/

Общий словарь хранится в Supabase, прогресс у каждого пользователя свой. Можно учить в обе стороны, перемешивать карточки, добавлять свои слова и сохранять резервные копии.

- [Запуск и проверки](wordcards/README.md)
- [Хостинг, права доступа и состояние настройки почты](wordcards/HOSTING.md)

Регистрация по почте и паролю работает без подтверждения адреса. Восстановление пароля по почте пока недоступно: для него потребуется SMTP. Приватные ключи и локальные резервные копии в репозиторий не входят.
