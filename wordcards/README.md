# Слово

Приложение для английских слов и фраз на HTML, CSS и JavaScript. Локальный режим работает без сетевых запросов. Онлайн-режим использует Supabase для входа, общего словаря и личного прогресса.

## Запуск

Из папки `wordcards`:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:4173. Используйте один и тот же адрес и браузер: локальное хранилище привязано к адресу сайта, включая порт. Для переноса используйте экспорт и импорт. Приложение не подтверждает сохранение, если браузер отказал в записи.

Можно открыть `dist/index.html` напрямую, но для стабильного локального сохранения рекомендуется HTTP-сервер.

## Возможности

- Переворот карточки, скрытая английская подсказка, примеры на обороте.
- EN → RU и RU → EN, случайный порядок без повторений внутри подборки.
- Статусы «Учу» и «Запомнил», отдельные подборки, завершение сессии.
- Добавление, редактирование, удаление и поиск карточек.
- Экспорт / импорт JSON с проверкой формата и подтверждением замены.
- Сохранение карточек и прогресса в localStorage; обновление между вкладками.
- Клавиатура: пробел / Enter на карточке — переворот, стрелки — навигация.
- 18 стартовых карточек, все изначально в статусе «Учу».

Подборка фиксируется при выборе фильтра или перемешивания. Изменение статуса не убирает текущую карточку из сессии; следующая подборка учитывает новые статусы.

## Публикация

Подготовлены схема базы с RLS, клиент Supabase и GitHub Actions для Pages. Инструкция: [HOSTING.md](HOSTING.md). До заполнения `dist/config.js` приложение остаётся локальным. Рабочая онлайн-база и публикация требуют подключения аккаунтов владельца; файлы конфигурации по умолчанию не содержат ключей.

Перед переносом на онлайн-адрес экспортируйте локальные карточки. Онлайн-импорт добавляет новые слова в общий словарь и восстанавливает только ваш прогресс, не удаляя чужие карточки.
